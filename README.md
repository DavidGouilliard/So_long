Basic 2D game made with MLX functions to connect with X11.

To run on Linux :

install required packages :
`sudo apt-get install gcc make xorg libxext-dev libbsd-dev`
git clone Minilibx in So_long directory :
`git clone https://github.com/42Paris/minilibx-linux.git mlx`
compile the files :
`make`
run the executable with one of the valid map as argument :
`./so_long maps/valide.ber`
move the player with W A S D (qwerty) or espace with ESC
