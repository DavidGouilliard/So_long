# 🕹️ so_long – Basic 2D Game with MLX & X11

A simple 2D game made using **MiniLibX** to interface with **X11**.

---

## 🔧 Requirements

### ✅ Linux

Install the required packages:

```bash
sudo apt-get install gcc make xorg libxext-dev libbsd-dev

Clone the MiniLibX repository inside the project directory:

git clone https://github.com/42Paris/minilibx-linux.git minilibx-linux

🍎 macOS

Install XQuartz using Homebrew:

brew install --cask xquartz



⸻

⚙️ Build the Project

Compile the source files with:

make



⸻

▶️ Run the Game

Use a valid map as an argument:

./so_long maps/valid.ber



⸻

🎮 Controls
	•	W, A, S, D — Move the player (QWERTY layout)
	•	ESC — Exit the game
